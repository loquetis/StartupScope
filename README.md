# StartupScope 1.0.0

Lists everything that starts with Windows and lets you switch items off and on again, reversibly.

- **How it works:** a Python localhost-only server (127.0.0.1:8772, env `STARTUPSCOPE_PORT`) plus a web UI in a private Edge app window (same pattern as QuickFind, PulseScope, DupeHunter, SpeedLog, DriveDoctor): random per-launch token on every change request, strict CSP, text-only DOM building, minimized-window early-exit fix. Data in `%APPDATA%\StartupScope` (override `STARTUPSCOPE_DATA`).
- **Sources (all readable without admin):** Run keys (HKCU, HKLM, HKLM 32-bit) plus Policies\Explorer\Run (read-only), the per-user and all-users Startup folders (`.lnk` targets are read with a small built-in parser), scheduled tasks with a log-on or boot trigger (`Get-ScheduledTask` via a hidden PowerShell), and auto-start Win32 services (registry; svchost services use their ServiceDll; `@dll,-id` display names resolved with SHLoadIndirectString).
- **Publisher and signature:** WinVerifyTrust (no revocation or network lookups) on the item's file, then the Windows security catalog for catalog-signed system files; publisher is the signing certificate's subject, falling back to the file's CompanyName. Results are cached by path + size + mtime, checked in the background.
- **Boot impact:** from `Microsoft-Windows-Diagnostics-Performance/Operational` events 100 (boot time), 101 (app start slowed) and 103 (service start slowed) via `wevtutil`; shown as High (3 s+), Medium (1 s+) or Low, otherwise `n/a` (Windows only logs slowdowns; the log needs admin on some PCs, then everything says n/a).
- **Toggles:** HKCU Run entries and your Startup folder: the same `StartupApproved` values Task Manager writes (`...\Explorer\StartupApproved\Run`, `Run32`, `StartupFolder`; `02…` enabled, `03…`+FILETIME disabled); nothing is deleted. Tasks: `schtasks /change /enable|/disable` (your own tasks only without admin). Services: `sc config start= demand` (Manual, never Disabled), admin only, with a confirmation. HKLM items, other users' tasks and services show an "Admin" badge instead of failing; Windows' own tasks and services are protected.
- **Backups and undo:** every change first writes `%APPDATA%\StartupScope\backups\<time>-change<N>.json` (complete before-state) and appears under *Changes & undo* with an Undo button; `initial-snapshot.json` holds the list as first found.
- **Safety:** items are acted on by opaque id only (the browser never sends a registry path, task name or file path); commands run as argument lists (no shell); service and task names are validated; CSV export neutralises formulas; nothing is sent anywhere.
- **Tests:** `python tests/test_engine.py` (parsing, StartupApproved bytes, scan, signatures, impact, toggles, undo, backups, failures), `tests/test_server.py`, `tests/uitest.py` (headless Chrome; fake Windows from `tests/fakeplat.py`), `tests/test_should_exit.py`, and on Windows `tests/test_windows.py` (real registry/tasks/signatures; touches only `StartupScopeTest-*` items).
- **Not code-signed.** SmartScreen may warn.
