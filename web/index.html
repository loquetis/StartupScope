What this shows

Run keys (HKCU and HKLM), the two Startup folders, scheduled tasks that start at log on or at boot, and services set to start automatically. It reads them without administrator rights.

How disabling works

  • Run keys and Startup folders: the same StartupApproved setting Task Manager uses. Nothing is deleted; the program, shortcut or registry value stays exactly where it is.
  • Scheduled tasks: the task is switched off in Task Scheduler and can be switched back on. Windows' own tasks are protected.
  • Services: set to Manual (not Disabled), so anything that needs the service can still start it. Windows' own services are protected. Needs administrator rights.
  • Every change writes a backup file first and appears under “Changes & undo”.
